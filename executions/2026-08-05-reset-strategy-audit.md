# Puzzle Date built-in Start Over strategy audit

Audited 2026-08-05 from public HTML/JavaScript assets only. No browser profile, cookies, `localStorage`, `sessionStorage`, IndexedDB, or saved user state was inspected. “Selected keys” below means a narrow mutation supported by source evidence; “unsupported” means Puzzle Date should not offer Start Over until equally narrow evidence exists. Reloading is the final step after every selected-key mutation and must keep the iframe at its current URL.

| Game | Recommended mode | Exact mutation / reload behavior | Evidence | Preserved data | Confidence and risk |
|---|---|---|---|---|---|
| Connections | **unsupported** | None. Do not clear the NYT origin and do not claim a reload resets the daily board. | Public page `https://www.nytimes.com/games/connections` and its referenced `connections.b9446a37251c99d6d127.js` shell expose a signed-in NYT application with statistics/leaderboards, but this audit did not establish a single client key or object field that represents only the current attempt. | All NYT games data, account state, streaks, stats, preferences. | **High confidence that clear-all is unsafe; low confidence in any client reset.** NYT shares an origin with other games, so origin-wide clearing has unusually large blast radius. |
| Word 500 | **selected keys** | On the current `/game?mode=daily` URL, derive the active prefix as `lang + level` (the app reads `word500lang` and `word500level`). Remove only `${prefix}hints`, `${prefix}gameover`, and `${prefix}guess0` through `${prefix}guess7`; retain `${prefix}word`; then reload the same URL (never navigate to the landing page). | `https://word500.com/game-engine.js?v=5`: daily restore reads `lang + level + 'hints'`, `'gameover'`, and eight `'guess' + i` keys. Its own `clearDailyCache()` removes those plus the word for every language/level; the narrower current-prefix set avoids changing other modes. Existing user-provided evidence requires restarting the current daily URL. | Current daily answer, language/level choice, archive saves, and stats keys such as won/lost/streak; other language/level games. | **High.** Risk: prefix must be built inside the game origin from the two preference keys; if either is absent/invalid, abort rather than guess defaults. |
| FoxiMax | **selected keys** | Remove only `daily-letters` for the default English five-letter game, then reload. For another language/word length, use the exact `data_prefix('daily-letters')` rule from source; do not hard-code a guessed prefix. `game-state` need not be removed: source uses it for the undo setting, not the saved letter sequence. | Inline public source at `https://foximax.com/`: `get_letters()` restores daily progress from `get_data('daily-letters')`, validates the embedded day number, and initializes a fresh `dn + '-'` value when absent. `data_prefix()` documents language/length prefixing. | Daily words, statistics/streaks, settings, tutorial dismissal (`dama`), practice progress, and all unrelated keys. | **High for default English/5; medium for variants.** Abort if the runtime cannot reproduce `data_prefix()` exactly. |
| Verticle | **selected object fields** | For exact case-sensitive keys `gameState` and `gameOfDayState`, parse each JSON object and set `guesses: []` and `charStatuses: {}` while leaving `solution` and all other fields intact; write back and reload. Missing keys may remain missing. Abort on malformed JSON rather than deleting it. | `https://verticle.netlify.app/static/js/main.aa26a9a7.js`: constants are `gameState`, `gameOfDayState`, and separate `gameStats`; persisted state is `{guesses, solution, charStatuses}` and restore consumes those fields. This also resolves the user-provided lowercase descriptions (`gamestate`, `gameofthedaystate`) to the asset’s exact camel-case keys. | `solution`, separate `gameStats`, streak/history, theme, contrast, hard/speedrun/share preferences, and any extra object fields. | **High.** Object-field clearing is safer than removing the two whole objects and avoids touching stats. |
| Waffle | **unsupported** | None. Reload-only is not Start Over, and clear-all must not be exposed. | Public `https://wafflegame.net/daily` HTML states that stats remain on-device and may also sync to an account. Referenced bundles are minified/split; this audit did not verify a current-puzzle-only key or transform. | Local/cloud stats, streaks, account/session state, preferences, archive/challenge data. | **High confidence that clear-all is unsafe; low confidence in a narrow reset.** Account sync can also restore or overwrite state unexpectedly. |
| Unwordle | **unsupported** | None. Do not clear storage or advertise reload as reset. | Public `https://unwordle.org/?daily=1` references split/minified Next bundles including `index-67b06989ad331934.js` and `735-f91e7433c56692ec.js`. The inspected assets expose daily and multi-mode statistics but no verified, isolated current-attempt key. | Daily/other-mode stats, streaks, fastest solve, settings, builder data. | **Medium-high.** The source was accessible but split/minified; no safe key was established. |
| 4 × 3 | **selected key** | Remove exactly `x43_game_${dailyKey}` for the currently loaded puzzle, then reload (or invoke the page’s own `resetPuzzle()` if protocol support is deliberately added). Do not remove every `x43_game_` key. The current `dailyKey` must be obtained from authoritative page state; abort if unavailable. | Inline public source at `https://www.hankgreen.com/fourbythree/`: restore reads `x43_game_` + `dailyKey`; its own `resetPuzzle()` computes `gameKey()`, removes only that key, and rebuilds the board. Separate keys include `x43_history`, `x43_stats`, achievements, cards, and preferences. | History, stats, achievements, cards, ad/region preferences, other dates’ game saves. | **High for the key semantics; medium implementation risk** because the suffix is dynamic. Prefix-wide deletion is explicitly unsafe. |
| Chain It | **unsupported** | None. Reload-only does not establish a fresh board; do not clear the Puzzlit origin. | `https://www.puzzlitapp.com/game/ChainIt` returned a hosted application shell/hydration payload, but no readable current-attempt storage contract or isolated key was established from public assets. | Puzzlit account/session, stats, other games on the shared origin, settings and progress. | **High confidence that clear-all is unsafe; low confidence in a narrow reset.** Shared-origin blast radius is material. |
| Word Salad | **unsupported** | None. In particular, do not use clear-all. | `https://wordsalad.online/` references Capacitor assets and `https://lngtd.com/wordsalad.js`; the latter did not expose a verifiable current-attempt key in the fetched public response. Existing user-provided evidence requires preserving tutorial/progress between sessions. | Tutorial dismissal, session-to-session progress, stats/preferences, and any app data. | **High confidence that clear-all violates the preservation requirement; low confidence in a narrow reset.** Reload-only may preserve rather than restart the puzzle. |
| Full Circle Friday | **selected key** | Remove only `fullCircleGameState`, then reload the same `fullcircle.html` URL. | `https://fullcirclefriday.com/miniJS/scriptV7-mini.js`: `saveGameState()` writes `fullCircleGameState`; `loadGameState()` reads it and already removes it when `gameId` changes. Stats update through authenticated server calls and are not stored in that object. | Authentication cookie (not touched), server stats, preferences and unrelated origin data. | **High.** A completed game may already have sent a stats update; Start Over clears the local board but must not promise to reverse server-recorded statistics. |
| Poople | **selected key** | Remove only `guesses`, then reload. Preserve `games`, `streak`, `bestStreak`, `dateLastPlayed`, and `dateLastWon`. | `https://poople.io/assets/index-B4nMajqv.js`: `Xr()` reads and `gc()` writes `guesses`; separate functions read/write `games`, streaks, and play/win dates. This agrees with existing user-provided key evidence. | Lifetime wins/distribution, current/best streak, play/win dates, preferences and unrelated keys. | **High.** Existing extension behavior that dismisses the post-reset “How to play Poople” modal is UI-only and does not justify any broader deletion. |

## Outcome

Safe candidates are Word 500, FoxiMax, Verticle, 4 × 3, Full Circle Friday, and Poople. No built-in game requires or justifies **clear-all**. Connections, Waffle, Unwordle, Chain It, and Word Salad should remain unsupported rather than receive a destructive or misleading Start Over button.

Sources that limited certainty: Waffle and Unwordle use split/minified bundles; Chain It returned an application shell without a readable storage contract; Word Salad’s externally referenced application script yielded no verifiable storage identifiers. These limitations are recorded as unsupported, not treated as evidence for guessed keys.
