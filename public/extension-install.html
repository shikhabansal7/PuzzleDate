Puzzle Date companion

Play every game inside Puzzle Date

Install this small Chrome extension to embed the full game rotation in Puzzle Date, automatically embed games added with the plus button, and make “Start Over” work for supported games.

Version 1.0.11 also blocks common ads and trackers—including Word 500's verified ad services—while games are embedded inside Puzzle Date. In recognized cookie-consent dialogs, it automatically rejects or declines optional cookies, or limits consent to necessary cookies. If no privacy-preserving choice exists, it dismisses or hides the recognized banner. This is best-effort, not universal, and never chooses “Accept all.” Ordinary browsing is unaffected.

Download the Chrome extension

In Puzzle Date, the light beside Extension is red when the extension is missing, yellow when an update is available, and green when version 1.0.11 is ready.

Install in Google Chrome

  1. Open the downloaded ZIP, which creates an unzipped folder.
  2. In Chrome, open chrome://extensions.
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked, then select the unzipped folder that directly contains manifest.json.
  5. Refresh Puzzle Date if it was already open.

Update an existing installation

  1. Download and unzip the new version 1.0.11 folder.
  2. Open chrome://extensions.
  3. On the Puzzle Date Game Reset card, click Remove, then choose Load unpacked and select the new folder that directly contains manifest.json.
  4. Refresh Puzzle Date. The extension card should show version 1.0.11.

What “Start Over” resets

For supported built-in games—Connections, Word 500, FoxiMax, Verticle, 4 × 3, Full Circle Friday, and Poople—Puzzle Date uses a narrow reset for the current puzzle instead of clearing all site storage.

Warning for games added with the plus button: “Start Over” deletes all localStorage for that added game’s origin and reloads it. This may erase the game’s statistics, tutorial completion, settings, and other saved progress. Cookies, session storage, IndexedDB, and caches are not cleared.

Keep the selected folder on your computer. This extension removes only iframe-blocking response headers for Puzzle Date’s built-in game domains and hostnames registered from the plus button; it does not change those sites when you visit them in a normal tab.
